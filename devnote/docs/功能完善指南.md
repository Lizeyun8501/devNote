## 一、OCR 模型文件下载与加载

### 1.1 功能说明

OCR（光学字符识别）功能使用 `ocrs` 纯 Rust 引擎，需要下载预训练模型文件才能正常工作。

### 1.2 模型文件下载

`ocrs` 需要两个模型文件：
- **文本检测模型**：检测图片中的文本区域
- **文本识别模型**：识别检测到的文本内容

#### 下载地址

```bash
# 创建模型目录
mkdir -p ~/.devnote/models

# 下载文本检测模型（约 10MB）
curl -L -o ~/.devnote/models/text-detection.rten \
  https://github.com/robertknight/ocrs/releases/download/v0.10.0/text-detection.rten

# 下载文本识别模型（约 15MB）
curl -L -o ~/.devnote/models/text-recognition.rten \
  https://github.com/robertknight/ocrs/releases/download/v0.10.0/text-recognition.rten
```

#### 备用下载方式

如果 GitHub 下载速度慢，可使用以下镜像：

```bash
# 使用国内镜像（示例，需替换为实际镜像地址）
# wget -O ~/.devnote/models/text-detection.rten https://mirror.example.com/ocrs/text-detection.rten
# wget -O ~/.devnote/models/text-recognition.rten https://mirror.example.com/ocrs/text-recognition.rten
```

### 1.3 代码集成

修改 `/workspace/devnote/rust-core/devnote-extensions/src/ocr.rs`，取消 TODO 注释并实现模型加载：

```rust
use anyhow::{Context, Result};
use std::path::PathBuf;
use std::sync::OnceLock;

/// 模型文件路径
fn get_model_dir() -> PathBuf {
    // 优先使用环境变量指定的路径
    if let Ok(path) = std::env::var("DEVNOTE_OCR_MODEL_DIR") {
        return PathBuf::from(path);
    }

    // 默认路径：用户主目录下的 .devnote/models
    if let Some(home) = dirs::home_dir() {
        return home.join(".devnote").join("models");
    }

    // 回退到当前目录
    PathBuf::from("./models")
}

/// OCR 引擎
pub struct OcrEngine {
    detection_model_path: PathBuf,
    recognition_model_path: PathBuf,
    initialized: bool,
}

impl OcrEngine {
    pub fn new() -> Self {
        let model_dir = get_model_dir();
        Self {
            detection_model_path: model_dir.join("text-detection.rten"),
            recognition_model_path: model_dir.join("text-recognition.rten"),
            initialized: false,
        }
    }

    /// 检查模型文件是否存在
    pub fn check_models(&self) -> Result<bool> {
        let detection_exists = self.detection_model_path.exists();
        let recognition_exists = self.recognition_model_path.exists();

        if !detection_exists {
            tracing::warn!("OCR 检测模型不存在: {:?}", self.detection_model_path);
        }
        if !recognition_exists {
            tracing::warn!("OCR 识别模型不存在: {:?}", self.recognition_model_path);
        }

        Ok(detection_exists && recognition_exists)
    }

    /// 从 base64 编码的图片识别文字
    pub fn recognize_from_base64(&mut self, image_base64: &str) -> Result<OcrResult> {
        // 检查模型
        if !self.check_models()? {
            return Err(anyhow::anyhow!(
                "OCR 模型文件未找到。请下载模型文件到 ~/.devnote/models/ 目录。\n\
                 下载地址：https://github.com/robertknight/ocrs/releases"
            ));
        }

        // 解码 base64
        let image_bytes = base64_decode(image_base64)?;

        // 解码图片
        let img = image::load_from_memory(&image_bytes)
            .context("无法解码图片，请确保是有效的 PNG/JPEG/WebP 格式")?;

        // 转为 RGB
        let rgb = img.to_rgb8();

        // 使用 ocrs 进行识别
        let img_vec: Vec<u8> = rgb.as_raw().clone();
        let img_info = ocrs::ImageInfo {
            width: rgb.width() as usize,
            height: rgb.height() as usize,
            data: &img_vec,
        };

        // 创建 OCR 输入
        let input = ocrs::OcrInput::from_image(img_info)
            .context("无法创建 OCR 输入")?;

        // 加载模型并创建引擎
        let ocr_engine = ocrs::OcrEngine::new(&ocrs::OcrEngineParams {
            detection_model: Some(
                ocrs::Model::load_mmap(&self.detection_model_path)
                    .context("无法加载检测模型")?
            ),
            recognition_model: Some(
                ocrs::Model::load_mmap(&self.recognition_model_path)
                    .context("无法加载识别模型")?
            ),
            decode_method: ocrs::DecodeMethod::Greedy,
        }).context("无法创建 OCR 引擎")?;

        // 执行识别
        let output = ocr_engine.detect(&input)
            .context("OCR 识别失败")?;

        // 提取文本
        let mut lines = Vec::new();
        for line in output.lines {
            let line_text: String = line.to_string();
            if !line_text.trim().is_empty() {
                lines.push(line_text);
            }
        }

        let text = lines.join("\n");
        self.initialized = true;

        Ok(OcrResult {
            text,
            lines,
            confidence: 0.85, // ocrs 不提供置信度，使用默认值
        })
    }
}
```

## 二、语音转文字（Whisper.cpp）集成

### 2.1 功能说明

语音转文字功能使用 OpenAI Whisper 模型进行本地语音识别，支持离线使用，保护用户隐私。

### 2.2 技术选型

推荐使用 `whisper-rs`（Whisper.cpp 的 Rust 绑定），性能优秀且跨平台支持好。

### 2.3 添加依赖

### 2.4 模型文件下载

Whisper 提供多种大小的模型，根据设备性能选择：

| 模型 | 文件大小 | 内存需求 | 速度 | 准确度 |
|------|---------|---------|------|--------|
| tiny | 75 MB | ~390 MB | 最快 | 一般 |
| base | 142 MB | ~500 MB | 快 | 较好 |
| small | 466 MB | ~1.0 GB | 中等 | 好 |
| medium | 1.5 GB | ~2.6 GB | 慢 | 很好 |
| large | 2.9 GB | ~4.7 GB | 最慢 | 最好 |

推荐使用 `base` 或 `small` 模型，平衡速度和准确度。

```bash
# 创建模型目录
mkdir -p ~/.devnote/models/whisper

# 下载 base 模型（推荐，适合大多数场景）
curl -L -o ~/.devnote/models/whisper/ggml-base.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin

# 或下载 small 模型（更高准确度）
curl -L -o ~/.devnote/models/whisper/ggml-small.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin

# 下载中文优化模型（可选）
curl -L -o ~/.devnote/models/whisper/ggml-small-zh.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin
```

### 2.5 代码实现

创建 `/workspace/devnote/rust-core/devnote-asr/src/lib.rs`：

```rust
//! 语音转文字模块
//! 基于 whisper.cpp 实现本地语音识别

use anyhow::{Context, Result};
use std::path::PathBuf;
use whisper_rs::{FullParams, SamplingStrategy, WhisperContext, WhisperContextParameters};

/// 转写结果
#[derive(Debug, Clone)]
pub struct TranscribeResult {
    /// 识别出的全文
    pub text: String,
    /// 音频时长（毫秒）
    pub duration_ms: u64,
    /// 分段结果
    pub segments: Vec<TranscriptSegment>,
}

/// 转写片段
#[derive(Debug, Clone)]
pub struct TranscriptSegment {
    pub text: String,
    pub start_ms: u64,
    pub end_ms: u64,
}

/// 语音转文字引擎
pub struct AsrEngine {
    model_path: PathBuf,
    ctx: Option<WhisperContext>,
}

impl AsrEngine {
    pub fn new() -> Self {
        let model_path = Self::get_model_path();
        Self {
            model_path,
            ctx: None,
        }
    }

    /// 获取模型路径
    fn get_model_path() -> PathBuf {
        // 优先使用环境变量
        if let Ok(path) = std::env::var("DEVNOTE_WHISPER_MODEL") {
            return PathBuf::from(path);
        }

        // 默认路径
        if let Some(home) = dirs::home_dir() {
            return home
                .join(".devnote")
                .join("models")
                .join("whisper")
                .join("ggml-base.bin");
        }

        PathBuf::from("./models/whisper/ggml-base.bin")
    }

    /// 检查模型是否存在
    pub fn check_model(&self) -> Result<bool> {
        if !self.model_path.exists() {
            tracing::warn!("Whisper 模型不存在: {:?}", self.model_path);
            return Ok(false);
        }
        Ok(true)
    }

    /// 初始化引擎（加载模型）
    pub fn init(&mut self) -> Result<()> {
        if !self.check_model()? {
            return Err(anyhow::anyhow!(
                "Whisper 模型文件未找到。请下载模型文件到 ~/.devnote/models/whisper/ 目录。\n\
                 下载地址：https://huggingface.co/ggerganov/whisper.cpp"
            ));
        }

        let ctx_params = WhisperContextParameters::default();
        let ctx = WhisperContext::new_with_params(
            self.model_path.to_str().unwrap(),
            ctx_params,
        ).context("无法加载 Whisper 模型")?;

        self.ctx = Some(ctx);
        Ok(())
    }

    /// 转写音频文件
    pub fn transcribe(&mut self, audio_path: &str, lang: &str) -> Result<TranscribeResult> {
        // 确保引擎已初始化
        if self.ctx.is_none() {
            self.init()?;
        }

        let ctx = self.ctx.as_ref().unwrap();

        // 读取音频文件（需要转换为 WAV 格式或使用 ffmpeg 解码）
        let audio_data = self.load_audio(audio_path)?;

        // 创建转写状态
        let mut state = ctx.create_state()
            .context("无法创建转写状态")?;

        // 配置转写参数
        let mut params = FullParams::new(SamplingStrategy::Greedy { best_of: 1 });

        // 设置语言
        params.set_language(Some(match lang {
            "zh" | "zh-CN" => "zh",
            "en" => "en",
            "ja" => "ja",
            "ko" => "ko",
            _ => "auto",
        }));

        // 启用翻译模式（将外语翻译为英语，可选）
        // params.set_translate(true);

        // 执行转写
        state.full(params, &audio_data[..])
            .context("语音转写失败")?;

        // 提取结果
        let num_segments = state.full_n_segments()
            .context("无法获取分段数量")?;

        let mut segments = Vec::new();
        let mut full_text = String::new();

        for i in 0..num_segments {
            let text = state.full_get_segment_text(i)
                .context("无法获取分段文本")?;
            let start = state.full_get_segment_t0(i)
                .context("无法获取分段开始时间")?;
            let end = state.full_get_segment_t1(i)
                .context("无法获取分段结束时间")?;

            // Whisper 时间单位是 centiseconds（百分之一秒）
            segments.push(TranscriptSegment {
                text: text.clone(),
                start_ms: start as u64 * 10,
                end_ms: end as u64 * 10,
            });

            full_text.push_str(&text);
        }

        // 计算总时长
        let duration_ms = segments.last()
            .map(|s| s.end_ms)
            .unwrap_or(0);

        Ok(TranscribeResult {
            text: full_text,
            duration_ms,
            segments,
        })
    }

    /// 加载音频文件
    fn load_audio(&self, audio_path: &str) -> Result<Vec<f32>> {
        // 使用 ffmpeg 或 symphonia 解码音频
        // 这里提供简化实现，实际需要集成音频解码库

        // 方案1：使用 ffmpeg 命令行工具（需要系统安装 ffmpeg）
        let output = std::process::Command::new("ffmpeg")
            .args([
                "-i", audio_path,
                "-f", "f32le",
                "-ac", "1",  // 单声道
                "-ar", "16000",  // 16kHz 采样率
                "-",
            ])
            .output()
            .context("无法执行 ffmpeg，请确保已安装 ffmpeg")?;

        if !output.status.success() {
            return Err(anyhow::anyhow!(
                "音频解码失败: {}",
                String::from_utf8_lossy(&output.stderr)
            ));
        }

        // 将字节转换为 f32
        let bytes = output.stdout;
        let samples: Vec<f32> = bytes
            .chunks_exact(4)
            .map(|chunk| {
                f32::from_le_bytes([chunk[0], chunk[1], chunk[2], chunk[3]])
            })
            .collect();

        Ok(samples)
    }
}

impl Default for AsrEngine {
    fn default() -> Self {
        Self::new()
    }
}
```

## 三、手写转文字（平台原生 API）集成

### 3.1 功能说明

手写转文字功能将用户的手写笔触转换为可编辑的文字，支持中文和英文手写识别。

### 3.2 技术方案

由于各平台的手写识别 API 不同，需要使用平台通道（Platform Channel）调用原生 API：

| 平台 | 原生 API | 支持语言 |
|------|---------|---------|
| iOS | Vision Framework (VNRecognizeHandwritingRequest) | 英文 |
| Android | ML Kit Digital Ink Recognition | 多语言 |
| macOS | Vision Framework | 英文 |
| Windows | Windows AI | 英文 |

### 3.3 iOS 实现

#### 3.3.1 创建 Swift 插件

创建 `ios/Classes/HandwritingRecognition.swift`：

```swift
import Flutter
import Vision

public class HandwritingRecognition: NSObject, FlutterPlugin {
    public static func register(with registrar: FlutterPluginRegistrar) {
        let channel = FlutterMethodChannel(
            name: "devnote.dev/handwriting_recognition",
            binaryMessenger: registrar.messenger()
        )
        let instance = HandwritingRecognition()
        registrar.addMethodCallDelegate(instance, channel: channel)
    }

    public func handle(_ call: FlutterMethodCall, result: @escaping FlutterResult) {
        if call.method == "recognize" {
            guard let args = call.arguments as? [String: Any],
                  let strokes = args["strokes"] as? [[[String: Double]]] else {
                result(FlutterError(code: "INVALID_ARGS", message: "无效参数", details: nil))
                return
            }
            recognizeHandwriting(strokes: strokes, result: result)
        } else {
            result(FlutterMethodNotImplemented)
        }
    }

    private func recognizeHandwriting(strokes: [[[String: Double]]], result: @escaping FlutterResult) {
        // 创建手写识别请求
        let request = VNRecognizeHandwritingRequest { request, error in
            if let error = error {
                result(FlutterError(code: "RECOGNITION_ERROR", message: error.localizedDescription, details: nil))
                return
            }

            guard let observations = request.results as? [VNRecognizedTextObservation] else {
                result("")
                return
            }

            let recognizedText = observations
                .compactMap { $0.topCandidates(1).first?.string }
                .joined(separator: "\n")

            result(recognizedText)
        }

        // 将笔触转换为 VNStrokePoint
        // 注意：iOS Vision Framework 的手写识别需要特定的输入格式
        // 这里提供简化实现，实际需要将 InkStroke 转换为 VNStrokePoint

        // 执行识别
        let handler = VNSequenceRequestHandler()
        do {
            try handler.perform([request], on: strokes as! VNDrawingRequest.Revision)
        } catch {
            result(FlutterError(code: "RECOGNITION_ERROR", message: error.localizedDescription, details: nil))
        }
    }
}
```

#### 3.4.2 创建 Kotlin 插件

创建 `android/app/src/main/kotlin/devnote/dev/HandwritingRecognition.kt`：

```kotlin
package devnote.dev

import android.content.Context
import com.google.mlkit.vision.digitalink.*
import io.flutter.plugin.common.MethodCall
import io.flutter.plugin.common.MethodChannel

class HandwritingRecognition(private val context: Context) : MethodChannel.MethodCallHandler {
    private var recognizer: DigitalInkRecognizer? = null

    override fun onMethodCall(call: MethodCall, result: MethodChannel.Result) {
        when (call.method) {
            "recognize" -> {
                val strokes = call.argument<List<List<Map<String, Double>>>>("strokes")
                val language = call.argument<String>("language") ?: "zh"
                recognizeHandwriting(strokes, language, result)
            }
            "downloadModel" -> {
                val language = call.argument<String>("language") ?: "zh"
                downloadModel(language, result)
            }
            else -> result.notImplemented()
        }
    }

    private fun recognizeHandwriting(
        strokes: List<List<Map<String, Double>>>?,
        language: String,
        result: MethodChannel.Result
    ) {
        if (strokes == null) {
            result.error("INVALID_ARGS", "无效参数", null)
            return
        }

        // 初始化识别器
        if (recognizer == null) {
            val identifier = DigitalInkRecognitionModelIdentifier.fromLanguageTag(language)
            if (identifier == null) {
                result.error("UNSUPPORTED_LANGUAGE", "不支持的语言: $language", null)
                return
            }

            val model = DigitalInkRecognitionModel.builder(identifier).build()
            val options = DigitalInkRecognizerOptions.builder(model).build()
            recognizer = DigitalInkRecognition.getClient(options)
        }

        // 将笔触转换为 Ink 对象
        val ink = convertStrokesToInk(strokes)

        // 执行识别
        recognizer?.recognize(ink)
            ?.addOnSuccessListener { recognitionResult ->
                val text = recognitionResult.results
                    .mapNotNull { it.text }
                    .joinToString("\n")
                result.success(text)
            }
            ?.addOnFailureListener { e ->
                result.error("RECOGNITION_ERROR", e.message, null)
            }
    }

    private fun convertStrokesToInk(strokes: List<List<Map<String, Double>>>): Ink {
        val inkBuilder = Ink.builder()

        for (strokeData in strokes) {
            val strokeBuilder = Ink.Stroke.builder()
            for (point in strokeData) {
                val x = point["x"]?.toFloat() ?: 0f
                val y = point["y"]?.toFloat() ?: 0f
                val t = point["t"]?.toLong() ?: System.currentTimeMillis()
                strokeBuilder.addPoint(Ink.Point.create(x, y, t))
            }
            inkBuilder.addStroke(strokeBuilder.build())
        }

        return inkBuilder.build()
    }

    private fun downloadModel(language: String, result: MethodChannel.Result) {
        val identifier = DigitalInkRecognitionModelIdentifier.fromLanguageTag(language)
        if (identifier == null) {
            result.error("UNSUPPORTED_LANGUAGE", "不支持的语言: $language", null)
            return
        }

        val model = DigitalInkRecognitionModel.builder(identifier).build()
        val remoteModelManager = RemoteModelManager.getInstance()

        remoteModelManager.download(model, DownloadConditions.Builder().build())
            .addOnSuccessListener {
                result.success(true)
            }
            .addOnFailureListener { e ->
                result.error("DOWNLOAD_ERROR", e.message, null)
            }
    }
}
```

```dart
import 'package:flutter/services.dart';
import '../models/ink_stroke.dart';

class HandwritingRecognitionService {
  static const _channel = MethodChannel('devnote.dev/handwriting_recognition');

  /// 识别手写笔触
  Future<String> recognize(List<InkStroke> strokes, String lang) async {
    try {
      // 将 InkStroke 转换为平台通道格式
      final strokesData = strokes.map((stroke) {
        return stroke.points.map((point) {
          return {
            'x': point.x,
            'y': point.y,
            't': DateTime.now().millisecondsSinceEpoch,
          };
        }).toList();
      }).toList();

      final result = await _channel.invokeMethod<String>(
        'recognize',
        {
          'strokes': strokesData,
          'language': lang,
        },
      );

      return result ?? '';
    } on PlatformException catch (e) {
      print('手写识别失败: ${e.message}');
      return '';
    }
  }

  /// 下载语言模型（Android ML Kit 需要先下载模型）
  Future<bool> downloadModel(String lang) async {
    try {
      final result = await _channel.invokeMethod<bool>(
        'downloadModel',
        {'language': lang},
      );
      return result ?? false;
    } on PlatformException catch (e) {
      print('模型下载失败: ${e.message}');
      return false;
    }
  }

  /// 检查平台是否支持手写识别
  Future<bool> isAvailable() async {
    // iOS 14+ 和 Android 6.0+ 支持
    // 实际检查逻辑可根据需要实现
    return true;
  }
}
```

## 四、浏览器扩展图标转换

### 4.1 功能说明

浏览器扩展需要 PNG 格式图标，当前提供了 SVG 源文件，需要转换为不同尺寸的 PNG。

### 4.2 图标尺寸要求

| 尺寸 | 用途 |
|------|------|
| 16x16 | 浏览器工具栏图标 |
| 48x48 | 扩展管理页面图标 |
| 128x128 | Chrome Web Store 图标 |

### 4.3 转换方法

#### 方法1：使用 ImageMagick（推荐）

```bash
# 安装 ImageMagick
# macOS: brew install imagemagick
# Ubuntu: sudo apt install imagemagick
# Windows: choco install imagemagick

cd /workspace/devnote/extensions/web-clipper

# 转换为各尺寸 PNG
convert icon.svg -resize 16x16 icons/icon16.png
convert icon.svg -resize 48x48 icons/icon48.png
convert icon.svg -resize 128x128 icons/icon128.png
```

#### 方法2：使用 rsvg-convert

```bash
# 安装 librsvg
# macOS: brew install librsvg
# Ubuntu: sudo apt install librsvg2-bin

cd /workspace/devnote/extensions/web-clipper

rsvg-convert -w 16 -h 16 icon.svg -o icons/icon16.png
rsvg-convert -w 48 -h 48 icon.svg -o icons/icon48.png
rsvg-convert -w 128 -h 128 icon.svg -o icons/icon128.png
```

#### 方法3：使用 Inkscape

```bash
# 安装 Inkscape
# macOS: brew install --cask inkscape
# Ubuntu: sudo apt install inkscape

cd /workspace/devnote/extensions/web-clipper

inkscape icon.svg -w 16 -h 16 -o icons/icon16.png
inkscape icon.svg -w 48 -h 48 -o icons/icon48.png
inkscape icon.svg -w 128 -h 128 -o icons/icon128.png
```

#### 方法4：在线转换

如果本地没有工具，可使用在线服务：

1. 打开 https://cloudconvert.com/svg-to-png
2. 上传 `icon.svg`
3. 设置输出尺寸（16/48/128）
4. 下载转换后的 PNG

### 4.4 图标设计建议

如果需要设计新图标，建议遵循以下规范：

1. **简洁明了**：图标应简洁，避免过多细节
2. **辨识度高**：在小尺寸（16x16）下仍能清晰辨认
3. **品牌一致**：与应用主图标风格一致
4. **透明背景**：使用透明背景 PNG
5. **适配主题**：提供亮色和暗色两种版本

### 4.5 自动化脚本

创建转换脚本 `extensions/web-clipper/scripts/generate_icons.sh`：

```bash
#!/bin/bash

# 图标生成脚本
# 需要安装 ImageMagick 或 rsvg-convert

SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
ICONS_DIR="$SCRIPT_DIR/../icons"
SVG_FILE="$SCRIPT_DIR/../icon.svg"

# 创建图标目录
mkdir -p "$ICONS_DIR"

# 检查工具
if command -v convert &> /dev/null; then
    echo "使用 ImageMagick 转换..."
    convert "$SVG_FILE" -resize 16x16 "$ICONS_DIR/icon16.png"
    convert "$SVG_FILE" -resize 48x48 "$ICONS_DIR/icon48.png"
    convert "$SVG_FILE" -resize 128x128 "$ICONS_DIR/icon128.png"
elif command -v rsvg-convert &> /dev/null; then
    echo "使用 rsvg-convert 转换..."
    rsvg-convert -w 16 -h 16 "$SVG_FILE" -o "$ICONS_DIR/icon16.png"
    rsvg-convert -w 48 -h 48 "$SVG_FILE" -o "$ICONS_DIR/icon48.png"
    rsvg-convert -w 128 -h 128 "$SVG_FILE" -o "$ICONS_DIR/icon128.png"
elif command -v inkscape &> /dev/null; then
    echo "使用 Inkscape 转换..."
    inkscape "$SVG_FILE" -w 16 -h 16 -o "$ICONS_DIR/icon16.png"
    inkscape "$SVG_FILE" -w 48 -h 48 -o "$ICONS_DIR/icon48.png"
    inkscape "$SVG_FILE" -w 128 -h 128 -o "$ICONS_DIR/icon128.png"
else
    echo "错误：未找到支持的转换工具"
    echo "请安装以下工具之一："
    echo "  - ImageMagick: brew install imagemagick"
    echo "  - librsvg: brew install librsvg"
    echo "  - Inkscape: brew install --cask inkscape"
    exit 1
fi

echo "图标生成完成："
ls -la "$ICONS_DIR"
```

## 六、常见问题

### Q1: OCR 模型下载速度慢怎么办？

**A**: 可以使用国内镜像或手动下载后上传到服务器：

```bash
# 使用代理
export https_proxy=http://127.0.0.1:7890
curl -L -o ~/.devnote/models/text-detection.rten ...

# 或使用 wget 断点续传
wget -c -O ~/.devnote/models/text-detection.rten ...
```

### Q2: Whisper 模型太大怎么办？

**A**: 使用 `tiny` 或 `base` 模型，或实现模型按需下载：

```dart
// 首次使用时提示用户下载
Future<void> ensureModelAvailable() async {
  final modelPath = '~/.devnote/models/whisper/ggml-base.bin';
  if (!File(modelPath).existsSync()) {
    // 显示下载对话框
    await showDownloadDialog();
    // 下载模型
    await downloadModel();
  }
}
```

### Q3: iOS 手写识别只支持英文？

**A**: iOS Vision Framework 的手写识别目前主要支持英文。如需中文手写识别，可以：

1. 使用第三方服务（如百度 OCR、腾讯 OCR）
2. 使用 ML Kit（需要 Android）
3. 训练自定义模型

### Q4: 浏览器扩展图标显示模糊？

**A**: 确保 PNG 图标尺寸正确，且使用透明背景：

```bash
# 检查图标尺寸
file icons/icon16.png
# 输出应为: PNG image data, 16 x 16, 8-bit/color RGBA
```
